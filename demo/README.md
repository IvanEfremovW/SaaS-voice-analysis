# Демо сравнения расшифровок

Запустите команды из корня репозитория. Для сборки нужны Python-зависимости STT и Node.js 20 от версии 20.19 или Node.js от версии 22.12.

```bash
.venv/bin/python -m pip install -r demo/requirements.txt
npm --prefix demo ci
npm --prefix demo run build
.venv/bin/python -m uvicorn demo.app:app --host 127.0.0.1 --port 8002
```

Откройте [127.0.0.1:8002](http://127.0.0.1:8002/), выберите запись, отметьте нужные варианты и нажмите «Расшифровать». Демо запускает выбранные варианты по очереди и показывает каждый результат по мере готовности. Интервалы по 30 секунд помогают сопоставлять текст. У всех колонок общий плеер, а таймкод каждой строки запускает воспроизведение нужной реплики. На широком экране колонки прокручиваются по горизонтали, на телефоне располагаются друг под другом внутри каждого интервала.

| Вариант | Настройки |
| --- | --- |
| Исходный Whisper (`current_recovery`) | VAD по умолчанию + восстановление пропущенной речи |
| VAD 5 с (`vad_5s`) | Один проход, пауза 5000 мс, padding 400 мс, threshold 0.5 |
| Тихая речь (`vad_5s_sensitive`) | То же, threshold 0.35 |
| Быстрый (`vad_5s_beam1`) | Обычный VAD 5 с, beam 1 вместо 5 |
| Всё аудио (`full_audio`) | Один проход без VAD и восстановления |
| T-one (`tone`) | Greedy, отдельная модель |

Четыре кандидата соответствуют [плану проверки Whisper](../docs/whisper_test_plan.md) и `stt/benchmark_variants.json`. Все варианты Whisper используют одну загруженную модель, ru, таймкоды слов, без промпта и контекста предыдущего текста. Восстановление включено только у исходного варианта. Порог паузы 5 с задаёт разделение речевых интервалов VAD; тишина в начале и конце тоже может обрезаться.

В заголовке результата показано время обработки на сервере: проверка аудио, чтение файла, распознавание и восстановление, если оно включено. Загрузка модели, ожидание очереди и передача файла по сети не входят в замер. Первый запуск включает прогрев, поэтому эти числа подходят для ориентировочного сравнения; повторяемые замеры делайте бенчмарком.

Строки расшифровки группируются по паузам и окончаниям фраз в STT. Плеер начинает воспроизведение на 0,3 секунды раньше начала строки.

Демо использует настройки и ограничения STT-сервиса из [документации модуля](../stt/README.md). По умолчанию сравниваются Whisper `large-v3-turbo` в пяти режимах и T-one. Модель Whisper меняется через `STT_MODEL_SIZE`, устройство — `STT_DEVICE`, тип вычислений — `STT_COMPUTE_TYPE`. Первый запрос загружает веса из локального кэша или скачивает их. Для T-one можно указать локальный файл весов через `TONE_MODEL_PATH`. Запись обрабатывается локально, оригинал воспроизводится из выбранного файла в браузере.

Список и параметры вариантов находятся в `demo/variants.json`. Для своего списка задайте `DEMO_VARIANTS_CONFIG=/полный/путь/variants.json` и перезапустите сервер. Интерфейс получает список через `GET /api/variants`, каждый прогон выполняется через `POST /api/transcribe/{id}`. Ответ содержит `transcript` и `elapsed_s`. Старые маршруты `/api/transcribe` и `/api/transcribe/t-one` сохранены.

Проверки без загрузки весов:

```bash
.venv/bin/python -m pytest -q demo/tests
npm --prefix demo run build
```
