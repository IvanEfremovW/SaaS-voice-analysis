# SaaS-voice-analysis

## Описание системы: 

Есть внутренняя CRM (Битрикс24), в которой происходят внешние звонки между СОП (Сотрудниками отдела продаж) и клиентами.  
CRM не является частью системы и служит лишь в виде источника получения аудиозаписей.

Разрабатываемая система аудиоанализа по REST API выгружает из CRM звуковую дорожку и приступает к анализу на основе общих требований и отдельно вносимых индивидуалных правил общения с клиентами.

В процессе анализа аудиозапись звонка: 
- Транскрибируется с помощью предоставляемой Сбером ML STT модели.
- Оценивается на соответствие общим и индивидуальным требованиям с детальными пояснениями оценки (не только числовая метрика, но и её обоснования).
- Оценка звонка выдаётся в Dashboard для РОПа (Руководителя отдела продаж).

### Dashboard
Dashboard представляет собой личный кабинет, в котором имеется перечень сотрудников и их звонки. 

Для каждого звонка должна иметься возможность: 
- Прослушать звонок
- Посмотреть детальную оценку
- Как отдельная фича: Посмотреть разметку звуковой дорожки с классификацией диалога (приветствие, часть скрипта, ответ клиента, негативное общение, тревожные ситуации и т.д.). 

### Кабинет администратора
Помимо dashboard в системе должен иметься кабинет администратора, позволяющий добавлять/исключать пользователей, контролировать доступы и лимиты (токены, количество звонков в архиве/для активного просмотра и т.д.).

## Технические требования: 

### Стек 
- **Machine learning**: Python, LangChain/LangGraph, Torch, Whisper, Transformers.
- **frontend/backend**: Node.js / TypeScript, React.
- **Databases**: PostgreSQL + PGVectr. 

### Производительность
- Обязательно использование очередей.
- Время обработки каждого звонка не должно превышать 30 минут.

### Внешние инструменты
- Взаимодействие с API Битрикс24.
- Взаимодействие с ML моделями должно производиться через внешний API. 

### Развёртывание
Проект должен быть развёрнут с использованием Docker.
