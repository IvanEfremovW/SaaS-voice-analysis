# Контекст модуля «Предобработка аудио»

Модуль приводит записи звонков к моно PCM float32, по умолчанию 16 кГц, затем применяет шумоподавление и VAD. Оркестратор получает склеенный речевой поток и исходные таймкоды речи. Итоговый выбор исследования — TorchAudio, стационарное спектральное шумоподавление и Silero.
