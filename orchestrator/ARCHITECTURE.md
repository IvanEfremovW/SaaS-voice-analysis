# Архитектура модуля «Оркестрация обработки звонка»

Загрузчик → опциональная предобработка → STT → опциональный пересчёт таймкодов к исходному звонку.

- [interfaces.py](interfaces.py) задаёт контракт загрузчика и протоколы сервисов. [loaders.py](loaders.py) реализует локальный загрузчик.
- [pipeline.py](pipeline.py) связывает компоненты. При включённой предобработке он передаёт в STT склеенную речь и использует исходные интервалы VAD для пересчёта таймкодов.
- [rest_clients.py](rest_clients.py) адаптирует HTTP-интерфейсы к протоколам оркестратора. [demo.py](demo.py) собирает компоненты для локального запуска.
