# Правила модуля «Оркестрация обработки звонка»

Следуй общим правилам из [корневого AGENTS.md](../AGENTS.md). Перед изменениями прочитай [контекст модуля](CONTEXT.md) и [его архитектуру](ARCHITECTURE.md).

Сохраняй заменяемость загрузчика, препроцессора и транскрибатора через контракты в `interfaces.py`. Пересчитывай таймкоды к исходной записи здесь. Проверяй режимы с предобработкой и без неё.

Проверка из корня репозитория

```bash
python -m pytest orchestrator/tests/
```
