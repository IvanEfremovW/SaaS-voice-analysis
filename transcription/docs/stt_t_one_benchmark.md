# Сравнение Whisper и T-one на звонках заказчика

Дата проверки 16 ноября 2026 года. Использованы пять MP3 из `samples/zakazchik/`. Аудио и распознанный текст обрабатывались локально.

## Условия

| Параметр | Настройка |
| --- | --- |
| CPU | Intel Core i5-12450H, привязка к четырём P-ядрам (`0,2,4,6`) |
| Whisper | `faster-whisper` 1.2.1, `large-v3-turbo`, INT8, русский язык, VAD и таймкоды слов |
| T-one | `voicekit-team/T-one` на ревизии `3c5b6c0`, веса `t-tech/T-one` на ревизии `106f3b0`, ONNX Runtime CPU |
| Декодеры T-one | Greedy и штатный beam search (ширина луча 200, KenLM, 5,46 ГБ) |
| Аудио | Декодирование PyAV в моно, 16 кГц для Whisper и 8 кГц для T-one |
| Замер | Время от чтения MP3 до получения результата, модель загружена заранее, один замер на запись |

Первый проход Whisper измерен вычитанием времени поиска и повторного распознавания пропусков из общего времени. Часть первого замера Whisper совпала с обработкой запроса в локальном демо, поэтому этот замер может быть завышен.

Ручных расшифровок для этих звонков нет. Измерение качества ограничено совпадениями с тремя фразами, которые указал пользователь, и сравнением текстов двух моделей. Для подсчёта ошибок относительно аудио потребуется ручной эталон.

Штатный API T-one возвращает границы фраз. В эксперименте таймкоды слов получены из кадров CTC. В режиме greedy использованы границы последовательностей символов, в режиме beam search использованы границы слов из результата декодера. Оба варианта передают слова в общую функцию `build_utterances`. Шаг CTC составляет 30 мс, абсолютная точность меток на этой выборке отдельно не измерялась.

Источники реализации. [T-one](https://github.com/voicekit-team/T-one) · [Веса T-one](https://huggingface.co/t-tech/T-one)

## Время на CPU

| Звонок | Аудио, с | Whisper первый проход, с | Whisper с восстановлением, с | T-one greedy, с |
| --- | ---: | ---: | ---: | ---: |
| `4425aca0` | 647,9 | 258,7 | 318,9 | 34,9 |
| `8063cf24` | 1307,8 | 360,8 | 375,6 | 70,0 |
| `c8a9bcd4` | 661,6 | 157,8 | 202,5 | 35,5 |
| `e5d0de5e` | 580,3 | 251,8 | 260,6 | 31,4 |
| `f2e75b00` | 547,0 | 145,1 | 157,8 | 29,4 |
| **Всего** | **3744,7** | **1174,2** | **1315,3** | **201,2** |

По сумме пяти замеров T-one greedy потратил в 5,8 раза меньше времени, чем первый проход Whisper, и в 6,5 раза меньше, чем Whisper с восстановлением. Отношение суммарного времени обработки к длительности аудио составило 0,054 для T-one greedy, 0,314 для первого прохода Whisper и 0,351 для текущего конвейера Whisper.

Контрольный прогон штатного T-one с KenLM на полном звонке `4425aca0` занял 37,2 с. Greedy занял 34,9 с на том же CPU.

### Три указанные фразы

Проверено максимальное число слов известной фразы, встретившихся в том же порядке в соответствующем интервале `4425aca0`. По краям добавлена одна секунда для учёта сдвига таймкодов. Совпадение всех слов проверено также на непрерывность.

| Интервал | Whisper первый проход | Whisper с восстановлением | T-one greedy |
| --- | ---: | ---: | ---: |
| `0:55–1:25` | 11/11 дословно | 11/11 дословно | 11/11 дословно |
| `1:53–2:06` | 7/7 дословно | 7/7 дословно | 6/7 |
| `5:41–6:14` | 0/5 | 0/5 | 2/5 |

На пяти звонках T-one greedy передал в общую сборку 7997 слов с таймкодами, из которых получилось 780 строк.

На `4425aca0` T-one с KenLM вернул 1425 слов с таймкодами и 135 готовых строк. Совпадения трёх фраз те же, что у greedy. При сравнении с первым проходом Whisper у варианта с KenLM получилось 32 слова только у Whisper, 302 слова только у T-one и 202 замены.
