# Контекст модуля «Детекция речи»

Модуль выделяет участки речи перед транскрибацией. Основной детектор — Silero с порогом 0.5. Для сравнения доступны WebRTC и энергетический детектор. Отдельная команда выводит разметку речи и тишины для всего файла.
