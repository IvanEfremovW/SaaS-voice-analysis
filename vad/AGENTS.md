# Правила модуля «Детекция речи»

Следуй общим правилам из [корневого AGENTS.md](../AGENTS.md). Перед изменениями прочитай [контекст модуля](CONTEXT.md) и [его архитектуру](ARCHITECTURE.md).

Реализуй новые детекторы через `BaseVAD` и регистрируй их в `get_vad`. Сохраняй таймкоды на исходной шкале в секундах. При отсутствии речи Silero возвращает пустой массив и пустой список интервалов.

Проверка из корня репозитория

```bash
python -m vad.detect audio_preprocessing/input_test_call.mp3
```
