# Детекция речи и тишины

Установите зависимости из корневого `requirements.txt`.
Запустите из корня репозитория:

```bash
python -m vad.detect audio_preprocessing/input_test_call.mp3
```

Скрипт выводит в stdout JSON-массив интервалов на шкале исходной записи.
Поля `start` и `end` заданы в секундах, а `type` принимает значения `speech` и
`silence`. Значение `silence` обозначает участки, где Silero не обнаружил речь,
включая фоновый шум и паузы. Если речи нет, массив содержит один интервал
`silence` на всю длительность записи. Порог детекции можно задать через
`--threshold` (по умолчанию `0.5`).

```json
[
  {"start": 0.0, "end": 1.2, "type": "silence"},
  {"start": 1.2, "end": 5.4, "type": "speech"},
  {"start": 5.4, "end": 6.0, "type": "silence"}
]
```
