# Архитектура модуля «Детекция речи»

Моно PCM float32 → адаптер VAD → склеенный речевой поток и список речевых интервалов.

- [interfaces.py](interfaces.py) описывает контракт, [vads.py](vads.py) реализует стратегии, [__init__.py](__init__.py) предоставляет фабрику.
- [detect.py](detect.py) загружает аудио через librosa и применяет Silero. CLI добавляет интервалы тишины к речевым сегментам и печатает JSON.
- [run_vad_experiment.py](run_vad_experiment.py) сравнивает детекторы и пишет отдельные артефакты бенчмарка.
